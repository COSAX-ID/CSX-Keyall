# Changelog — v1.0.1

## Changes

- **H2 Database**: H2 now uses the official JDBC driver (`org.h2.Driver`) instead of being forced to SQLite. The connection uses `jdbc:h2:file:` with MySQL compatibility mode (`MODE=MySQL`).
- **Upsert query**: H2 now uses `MERGE INTO ... KEY(data_key) VALUES (...)` syntax instead of SQLite's `INSERT OR REPLACE`.
- **Dependencies**: Added `com.h2database:h2:2.2.224` to `pom.xml`.

## Maintenance

- Version bumped from `1.0.0` to `1.0.1`.
- Updated `config.yml` comments to reflect H2 support.
- Added `changelog/` directory for release tracking.
