# Changelog — v1.0.2

## Changes

- **Multi-Version Support**: Plugin now supports Minecraft **1.20.x**, **1.21.x**, and **26.x** (1.22+).
- **API Dependency**: Switched from `spigot-api 1.21-R0.1-SNAPSHOT` to `paper-api 1.20.1-R0.1-SNAPSHOT` for broader version compatibility.
- **api-version**: Changed from `1.21` to `1.20` in `plugin.yml` to enable Paper's backward compatibility across all supported versions.
- **Folia Support**: Plugin now detects Folia at runtime and uses `GlobalRegionScheduler#runAtFixedRate` instead of Bukkit's `runTaskTimer`. A dedicated `FoliaHelper` class isolates Folia-specific APIs so no classloading errors occur on non-Folia servers.

## Maintenance

- Version bumped from `1.0.1` to `1.0.2`.
